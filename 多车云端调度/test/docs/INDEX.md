## 📞 获取帮助

### 遇到问题？

1. **查阅文档**
   - 先在上述文档中搜索解决方案
   - 查看"常见问题"章节

2. **检查控制台**
   - 打开浏览器开发者工具（F12）
   - 查看 Console 标签的错误信息

3. **验证环境**
   - 确认 Node.js 版本（v18.x 或 v20.x）
   - 确认 MQTT Broker 是否运行
   - 检查网络连接

4. **重新生成数据**
   - 点击"生成示例数据"按钮
   - 刷新页面重置状态
